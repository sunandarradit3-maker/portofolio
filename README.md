# DiTz Store Agency CMS Template

Scalable agency CMS starter untuk brand **DiTz Store**.

## Stack
- Next.js 15 App Router
- TypeScript
- TailwindCSS
- Shadcn-style UI primitives
- Framer Motion
- NextAuth / Better Auth ready
- PostgreSQL + Prisma
- Cloudinary-ready
- Vercel-first deployment

## Isi utama
- Public site: Home, Portfolio, Services, Pricing, Blog, About, Contact
- Admin panel: Dashboard, Portfolio, Blog, Services, Pricing, Testimonials, FAQ, Leads, Settings
- Prisma schema untuk semua tabel inti
- API skeleton
- Dokumentasi architecture, deployment, environment, dan UI layout

## Jalankan
```bash
pnpm install
cp .env.example .env
pnpm dev
```

## Catatan
Template ini sengaja dibuat modular agar mudah di-clone untuk unlimited client project dengan branding yang berbeda.
